Quick guide

  • Highlight / Pen — drag on the page. Each has preset colors plus a rainbow chip for any custom color. With the Hand tool, click a highlight or stroke to select it: drag to move, ✕ or Delete to erase, corners resize a highlight.
  • Cover (tip-ex) — drag an opaque box over anything you want hidden: text, a stamp, a whole paragraph. White by default (paper tints and black available too); once you save it bakes into the page and the content underneath is covered. Until then the Hand tool can still move, resize, or delete it — hover to find a white box on a white page.
  • Text — click and type. Enter starts a new line, Ctrl+Enter finishes, Esc cancels — so one text box can hold a whole paragraph. Hebrew and other languages are supported (right-to-left is handled automatically). To edit later, double-click it with the Hand tool or select it and press Enter — it opens in place, crisp, with the caret at the end, and every keystroke updates the box live.
  • Copying text boxes — select one and press Ctrl+C, then Ctrl+V pastes an identical box (words, colour, size, angle — everything) on this page or any other page. Ctrl+D or the ⧉ Copy button drops a copy right next to the original.
  • Styling text — select it with the Hand tool and the top bar gives you colour, size, bold, italic, alignment, rotation, line spacing and fade. Drag the round handle above the box to spin it (hold Shift to snap to 15°). Corners resize the whole box; the mid-edge handles stretch one direction only — sides for width, top/bottom for height.
  • Image — drag an image file straight onto the page, or use the Image tool and drag a box. With the Hand tool, drag to move or use the corners to resize.
  • Sign — draw a signature once (a tap leaves a dot, so dotted letters work), then click the page to place it. It lands as a live object: drag it into position, corners resize, ✕ or Delete removes it — it is only written into the file when you save. “Draw new signature” in the top bar replaces it.
  • Move around — drag the page with the Hand tool, or hold the right mouse button with any tool. Ctrl + wheel zooms.
  • Pages — drag thumbnails to reorder, or use a thumbnail's ⇅ to jump it to any page number. Each has ↺ ↻ rotate (90° left/right) and delete; the toolbar's ↺ ↻ turn the page you are viewing — or every selected page — and [ / ] do the same from the keyboard. Rotation is saved into the file. Ctrl+click (or Shift+click) thumbnails to select several pages, then move them together (drag or "Move…") or delete them in one go.
  • Insert PDF adds other PDFs at the beginning, end, or after a chosen page — you can pick several files at once in the dialog, or simply drop PDF files onto the window to append them. PNG/JPG images are welcome too: each becomes a full A4 page. Dropping images with no document open builds a brand-new PDF out of them.
  • Extract saves a page range to a new file.
  • Numbering puts page numbers on the document — choose the corner, the style (1, 1 / 12, Page 1 of 12, עמוד 1 מתוך 12, or your own), where counting starts, size and colour. It is stored as a rule, so if you add, delete, move or rotate a page the numbers correct themselves; re-opening a file numbered here brings the rule back rather than leaving stale numbers behind. Numbers you can see on screen are written into the file when you save.

Good to know

This tool adds text as overlays — it does not rewrite text already inside the PDF. "Sign" places a visible signature image; it is not a cryptographic digital signature.

סימון תפעול ידני — תוכנית זמנים של ענבר

לכל תמונה: אות:שניית_זינוק/שניית_עצירה, מופרד בפסיקים. הסימון נעשה על העמוד הנוכחי, בסמלים המקוריים של ענבר (+ = זינוק, ‡ = עצירה) בשורת ידני.ת.

⚡ קורא את הנקודות ישירות מקווי גבולות התמונות הכחולים שענבר מציירת בדיאגרמה. הרכב תמונות (אופציונלי, נשמר לצומת) משמש גיבוי לעמודים שבהם הקווים אינם ניתנים לקריאה.

ציר הזמן ושורת ידני.ת מזוהים אוטומטית מתוכן העמוד; אם הזיהוי נכשל נעשה שימוש בפריסת ענבר הסטנדרטית (A4).

הסימונים נשארים ניתנים לעריכה עד השמירה: לחיצה עם כלי היד בוחרת סימן — ✕ או Delete מוחקים, וחצים מזיזים. חישוב מחדש מחליף את הסימונים בעמוד. "🗑 מחק סימונים בגליון" מוחק את כל הסימונים בגליון הנוכחי בלבד. Ctrl+Z לביטול. לאחר שמירה הסימונים הופכים לחלק מהעמוד.

Numbering is a rule, not stamped-on marks: it is written when you save, and it re-numbers itself whenever you add, delete, move or rotate a page. Re-open a file numbered here and the rule comes back with it, so the numbers never double up.
